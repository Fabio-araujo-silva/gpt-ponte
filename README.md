# GPT Ponte

Transforma o ChatGPT aberto no seu navegador numa **API compatível com a da OpenAI**
(`/v1/chat/completions`), para você usar a sua assinatura do ChatGPT no OpenCode e em
qualquer outro cliente que fale "OpenAI".

```
OpenCode / SDK / curl ──HTTP──▶ ponte local (Node) ──WebSocket──▶ extensão ──▶ aba do chatgpt.com
```

> Projeto em construção. O guia completo de instalação entra neste README assim que a
> primeira versão estiver pronta.

## Aviso

Este projeto não tem nenhuma relação com a OpenAI. Os Termos de Uso do ChatGPT proíbem
extrair respostas de forma automatizada; usar esta ponte pode levar a limites ou ao
bloqueio da sua conta. Use por sua conta e risco.
